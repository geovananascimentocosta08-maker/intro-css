O que é o CSS

O CSS significa Cascading Style Sheets ou folhas de estilo em cascata

Sobre o CSS

Linguagem responsável por definir a aparência visual e organização dos elementos na tela

Como aplicar o CSS

Para o CSS, temos três abordagens:

  • CSS Inline
  • CSS Interno
  • CSS Externo

O que da para fazer com o CSS?

O CSS não serve apenas para colocar cor na página. Ele controla:

  • Cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamentos
  • responsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através do atributo style

Aplicando o CSS

Nessa abordagem, o CSS é aplicado dentro de de uma tag < head > dentro do < head > do documento HTML.

Aplicando o CSS Externo

Nessa abordagem, os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esse arquivo ao HTML, utilizamos o elemento de < link > no < head > da página.
